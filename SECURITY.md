# Security

Please do not post credentials, OAuth tokens, account data, or exploitable vulnerability details in public issues.

If GitHub private vulnerability reporting is available, use the repository's Security tab to report a vulnerability privately. If it is unavailable, open an issue asking the maintainer for a private reporting channel without including vulnerability details or secrets.

Only the latest beta is actively developed; no response-time or support guarantee is offered. Never attach your local `config.json` to a report. Lyrics Island stores Spotify credentials in its local user-data directory; treat that directory as sensitive.
